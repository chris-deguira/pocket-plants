About this site

Pocket Plants is a small static website. It exists to practice working with a real project on GitHub.

How the site is built

  • Plain HTML and CSS, with no build step.
  • Two short JavaScript files for the plant filter and the watering planner.
  • SVG illustrations that stay sharp at any size.
  • Hosting through GitHub Pages, straight from the main branch.

Accessibility

  • A skip link and landmark regions for keyboard and screen reader users.
  • Descriptive alt text on every illustration.
  • Light and dark color schemes that follow the system setting.
  • Controls that work with the keyboard alone.

Reporting a problem

Open an issue in the project repository and describe the page, the browser, and what looked wrong.
