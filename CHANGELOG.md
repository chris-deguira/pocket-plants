# Changelog

All notable changes to this project are recorded here.

## [1.0.0] - 2026-10-20

First stable release.

### Added

- A home page, a plants page, a care guide, and an about page.
- Six plants with light, watering, and pet-safety notes, each with an SVG illustration.
- A filter on the plants page for name, available light, and pet safety.
- A watering planner on the care page.
- Light and dark color schemes that follow the system setting.
- A check script and a GitHub Actions workflow that look for broken links, missing alt text, and absolute links.
- Issue templates, a pull request template, and contributing guidelines.
